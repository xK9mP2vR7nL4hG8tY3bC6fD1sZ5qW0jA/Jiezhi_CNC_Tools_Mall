# 杰帜数控刀具商城

[`jz.zhike.xyz`](https://jz.zhike.xyz/) 的响应式国内 B2B 数控刀具商城前端工程。

## v1.2.1 已实现

- **型号优先**：商品按“一级类目 → 型号家族 → SKU 规格”管理；同型号的大小、方向、材质、包装等在同一页面选择。
- **主夹 / 背夹独立分类**：两者均为一级入口与可筛选类目。
- **直接下单**：移除询价单，支持商品规格、采购车、企业结算信息、订单成功页、我的订单。
- **固定送货单**：提交订单后自动生成演示送货单，支持查看、浏览器打印与 CSV（可用 Excel 打开）导出。
- **发货规则**：统一呈现“18:30 前下单预计当天发，18:30 后预计下一发货日”的业务提示。
- **双角色登录**：独立的买家 / 卖家身份 Tab、演示会话与路由分流；卖家账号明确标注应由管理员开通。
- **买家企业中心**：企业采购金额、订单状态、我的订单、送货单、地址、批量下单、选型与采购分析入口。
- **卖家工作台**：订单审核/拒绝、正式生成送货单、确认发货、商品、客户、统计与公告管理入口。
- **真实行业图片**：已本地化授权明确的行业实拍，但标注为“非具体 SKU”；具体商品图需要杰帜自有或书面授权的型号实拍。

## 重要边界

## 本地运行

```bash
pnpm install
pnpm dev
pnpm test
pnpm build
pnpm test:e2e
```

如果终端无法以交互模式运行 `pnpm build`，可依次执行：

```bash
node_modules/.bin/tsc -b
node_modules/.bin/vite build
```
