# 假设、演示边界与待确认项

更新时间：2026-07-29。

## 已采用的保守实现

- 商品以“类目 → 型号家族 → SKU 规格”组织；主夹与背夹是两个独立一级类目。同型号的尺寸、方向、材质、包装等在同一型号页内选择。
- 询价流程已经移除。演示链路为：选择精确 SKU → 采购车/直接下单 → 提交订单 → 自动生成送货单 → 卖家审核/人工发货。
- 送货单使用用户提供的粉红联单视觉作为模板参考；演示编号为 `XS` 加连续六位流水，起始值为 `348999`。正式前必须确认前缀、起始值、重置周期、作废和多仓规则。
- 页面展示的“18:30 前下单当天发、18:30 后下一发货日”是用户明确给出的业务规则。当前原型使用浏览器中国时区时间演示；生产必须由服务端 `Asia/Shanghai` 时间、可售库存、仓库工作日历和临时截单规则共同判断。
- 税务页面的 13% 仅为演示选项，不代表杰帜实际税率、含税/未税算法或发票类型。现金、月结、当月结也仅是 UI 选择，月结必须改由卖家审批。
- 商品价格、库存、MOQ、交期、客户、订单和统计数据均是明确的原型数据，保存在浏览器本地；不代表可售库存、真实交易或财务记录。

## 真实图片边界

- `cnc-waterjet-public-domain.jpg` 是合法的公共领域加工场景照片。
- `tungsten-carbide-inserts-cc-by-sa-4.jpg`、`tool-holder-cc-by-sa-4.jpg` 为合法的 CC BY-SA 行业实拍，页面明确标为“行业实拍 · 非具体 SKU”。
- 这些图片不能被写为杰帜任何具体型号的实物、库存或性能证明。实际 SKU 页面应替换为杰帜自有或已书面授权、且能与型号/规格一一对应的照片；全部来源见 [`asset-manifest.csv`](./asset-manifest.csv)。

## 尚未确认，不能擅自写死

1. 送货单公司信息、正式纸张尺寸、编号规则、签字和盖章流程。
2. 税率、发票类型、价格体系、现金/月结/当月结定义及审批权限。
3. 仓库、物流方式、工作日/节假日、缺货与拆单规则。
4. 真实 SKU 台账、旧型号映射、店内编码和主夹/背夹分类字典。
5. ERP/WMS/CRM、支付服务、短信、对象存储、备份与权限系统的选型和账号。

在以上事项确认前，工程以演示数据和可替换接口边界继续推进，不以猜测冒充真实业务。
