# 买家 / 卖家双角色原型说明

更新时间：2026-07-29。

## 目标

新增的手机界面确认了商城存在两类身份：**买家企业采购账号**与**卖家运营账号**。两类账号不是同一个页面换一套文案，而是两条不同的业务路径：

```text
买家：浏览型号 → 选择 SKU → 采购车 → 登录 → 提交订单 → 查看订单 / 送货单 → 确认收货
卖家：卖家登录 → 工作台 → 审核或拒绝订单 → 正式生成送货单 → 打印 / 导出 → 人工发货
```

## 已实现的原型页面与路由

| 身份 | 页面 | 路由 | 已实现交互 |
|---|---|---|---|
| 公共 | 买家 / 卖家登录 | `/login` | Tab 切换、字段差异、协议勾选、手机号格式与验证码长度校验、演示快捷登录、原路返回。 |
| 买家 | 企业采购中心 | `/account` | 企业信息、采购金额、订单状态、订单/送货单、批量下单、选型和采购分析入口。 |
| 买家 | 我的订单 | `/orders` | 全部、待审核、待发货、待收货、已完成筛选；查看送货单；已发货订单可确认收货。 |
| 买家 | 订单确认 | `/checkout` | 自动带入演示账号的企业、联系人、手机；提交后写入订单快照和送货单预编号。 |
| 卖家 | 卖家工作台 | `/seller` | 今日访客、本月订单、本月成交额、商品/订单/客户/数据/送货单/公告快捷入口。 |
| 卖家 | 订单管理 | `/seller/orders` | 待处理、待发货、已发货、已完成筛选；确认订单、拒绝并填写说明、正式生成送货单、确认发货。 |
| 卖家 | 送货单管理 | `/seller/deliveries` | 按订单展示送货单状态，预览、浏览器打印、CSV（Excel 可打开）导出、确认发货。 |
| 卖家 | 送货单详情 | `/seller/delivery/:id` | 与买家单据同一份固定模板，但返回卖家送货单管理。 |

## 权限与订单规则（原型行为）

1. 商品可在未登录状态下浏览；结算、买家订单、企业中心、送货单需要买家身份。
2. 卖家工作台及其子路由需要卖家身份。买家直接访问卖家地址会回到卖家登录页。
3. 买家提交订单时，系统将：
   - 写入买家身份标识、收货/税务/结款/物流/商品 SKU 快照；
   - 自动预生成 `XS` 固定送货单编号；
   - 写入“买家提交订单”状态记录；
   - 按 18:30 规则展示预计发货时间（当前仅浏览器演示）。
4. 卖家确认订单后，订单进入可发货处理；“生成送货单”用于确认单据已可打印、盖实体章和安排发货。这样既保留“下单即生成编号”的业务要求，也满足卖家审核后再出库的流程。
5. 卖家拒绝、确认订单、生成送货单、确认发货，以及买家确认收货，都会在浏览器订单记录中追加操作时间和角色标记。

## 与手机参考稿一致的视觉决策

- 采用蓝白企业采购视觉、圆角白色信息卡、单一主操作按钮和清晰的红/绿/蓝状态文字。
- 登录页具有买家/卖家双 Tab；卖家额外填写企业名称，并明确“正式卖家账号由管理员开通”。
- 买家中心采用蓝色企业信息区、采购金额、订单状态捷径、企业工具箱与卖家服务入口。
- 卖家工作台采用深蓝运营信息区、三项经营指标、六个管理入口和型号化商品列表。
- 手机端使用五项以内的底部导航，保留安全区和 44px 以上的可点击区域；桌面端改为侧栏式卖家工作台。

## 原型边界（不可当作真实上线能力）

本轮登录、权限、订单状态、短信验证码、微信快捷登录和经营数据均为**浏览器本地演示**：

- 不发送真实短信，不接入微信 OAuth，不创建服务器端账号；
- `localStorage` 只能演示角色分流，不能提供真实权限保护；
- 价格、库存、税率、金额、发货时间和订单编号不应在生产环境由前端决定；
- CSV 导出为第一阶段的 Excel 兼容演示；正式版本应使用服务端生成的固定模板 `.xlsx`；
- 打印后仍需按实际业务加盖实体章，不做电子签章。

真实上线必须增加账号与企业组织、RBAC 权限、短信/微信服务、商品与库存 API、订单快照、状态机、审计日志、送货单序列、对象存储、备份和服务端导出。

## 验收用例

1. 未登录访问 `/orders`，跳转到买家登录；未登录访问 `/seller/orders`，跳转到卖家登录。
2. 买家登录后进入 `/account`，可进入订单中心；卖家登录后进入 `/seller`，可进入工作台。
3. 买家加入 SKU 并提交订单，生成订单号与 `XS` 送货单编号。
4. 卖家在订单管理中确认订单，确认“生成送货单”，再确认发货。
5. 买家订单状态同步显示为待发货 / 待收货，并可在已发货后确认收货。
6. 买家和卖家都可在各自的授权路径内查看同一张送货单；买家不能通过链接查看其他买家带有身份标识的订单。
