# v1.1 前端原型验收

## 已验收

- [x] 品牌统一为“杰帜数控刀具”。
- [x] 主夹、背夹为独立一级分类；同型号多规格在型号详情页中选择。
- [x] 历史询价链接重定向至结算，不再创建询价单。
- [x] 采购车、企业结算、税务/结算/物流选择、订单成功页和订单中心可运行。
- [x] 提交订单后自动生成固定模板送货单、`XS` 演示流水号、打印与 CSV 导出。
